# HEYUE Water — Public Website Learning Project

A static B2B water equipment website demonstration built for coursework.

## What this project demonstrates

- Application-based product organization: community refill, workplace and hospitality, institutional projects.
- Responsive semantic HTML and CSS with mobile layouts.
- Accessible JavaScript product filters and live result counts.
- Public source control and GitHub Pages deployment.

## Files

- `docs/index.html`: complete frontend, styles and filter interaction.
- `docs/assets/`: selected public product images and an illustrative scene.
- `LEARNING.md`: learning objectives and implementation notes.

No build step or dependencies are required. Open `docs/index.html` in a browser to preview.

## GitHub Pages setup

In this repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/docs**, then save.

For a repository named `heyue-water-homework` owned by `dampadvent`, the expected Pages address is `https://dampadvent.github.io/heyue-water-homework/`. This is an expected address, not a claim that deployment is already live.

## Project scope

This public learning demonstration is separate from the commercial website at https://www.heyuewater.com. It contains no administration system, credentials, customer data, payment integration or enquiry collection. Scene imagery is illustrative, not a customer case study.

Product names and selected specifications are provided for demonstration; final configuration and site suitability must be confirmed separately. Product images and branding remain the property of their respective rights holders. Their inclusion here does not grant a reuse license.
