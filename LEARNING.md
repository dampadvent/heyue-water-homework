# Learning Record

## Chapter 1 — Building and publishing a website

### Purpose
Translate a commercial water equipment business brief into an English B2B product browsing experience.

### Design decisions
- Lead with applications rather than a long technical specification table.
- Use water-inspired teal, soft green and white to create a clear visual hierarchy.
- Keep product photography visible and use plain English for buyer-facing descriptions.

### Implementation
- Semantic header, navigation, main, sections, product articles and footer.
- CSS grid with a single-column mobile layout.
- Native buttons with `aria-pressed` for application filters.
- A live result count, visible keyboard focus, a skip link and reduced-motion support.
- Relative image paths that work beneath a GitHub Pages project path.
- A buildless static site served from the `docs` directory.

### Publication boundary
The public coursework contains selected public-facing content only. The commercial repository, backend, admin access, credentials and customer information are excluded.

### Deployment checklist
- Create the public coursework repository.
- Upload this project's files.
- Enable GitHub Pages from `main` / `docs`.
- Open the published URL and test desktop/mobile display and all four filter buttons.
- Submit the public repository URL and verified GitHub Pages URL to the course.
